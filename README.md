# 一键更新书签

简体中文 · [English](README.en.md)

一键把当前网页的网址写入指定的 Chrome 书签。追剧时选好一个书签，停在当前剧集页面按 **Alt + S**，下次点原书签就能回到这一集。扩展只修改书签的网址，名称、文件夹和排序保持原样。

![扩展弹窗，显示已选书签和 Alt + S 快捷键](docs/popup.png)

## 安装

1. 下载或克隆本仓库。如果下载了 ZIP，请先解压。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的目录。
4. 从 Chrome 工具栏的扩展菜单打开「一键更新书签」。可以把扩展固定到工具栏，方便查看更新结果。

## 使用

1. 在弹窗中选择一个已有书签，点击「保存选择」。如果还没有书签，可以先用 Chrome 的收藏功能创建一个。
2. 打开要记录的 HTTP 或 HTTPS 网页，按 **Alt + S**。
3. 扩展图标显示 **OK** 后，下次直接点击原书签即可打开新网址。

打开弹窗时，如果当前网址与书签地址一致，下拉框会预选对应书签。同一网址有多个书签时，优先预选最近打开的一个。打开时间并列或都没有记录时，请从下拉框手动选择。点击「保存选择」后，快捷键才会更新新目标。

## 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 按快捷键没有反应 | 在弹窗点击「设置快捷键」，或打开 `chrome://extensions/shortcuts`，确认已绑定按键并检查是否冲突。 |
| 扩展图标显示 `ERR` | 将鼠标停在图标上查看原因。检查当前页是否为普通网页，以及选中的书签是否仍然存在。 |
| 打开书签后没有自动预选 | 预选依据当前网址精确匹配。网页跳转到其他地址后，可以手动选择原书签。 |

## 权限与数据

| 权限 | 用途 |
| --- | --- |
| `bookmarks` | 把已有书签列在弹窗中，并更新选定书签的网址。 |
| `activeTab` | 在打开弹窗或触发快捷键时读取当前标签页的网址。 |
| `storage` | 在当前 Chrome 配置文件中保存选中的书签 ID。 |

扩展在浏览器内处理数据，扩展本身不会向开发者或第三方服务器发送书签、网页地址或使用数据。

## 开发

项目使用 Chrome Manifest V3 和原生 JavaScript，无需安装依赖或运行构建。修改文件后，在 `chrome://extensions` 点击扩展的「重新加载」。提交改动前，可以用临时书签验证自动预选、保存选择和快捷键更新。
